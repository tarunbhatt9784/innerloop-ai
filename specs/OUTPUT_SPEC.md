# Daily Output Spec

Use this structure for a normal run.

## What I noticed

Give 2-4 concise evidence-grounded observations. Clearly separate what was written from your interpretation. Mention uncertainty if handwriting or meaning is unclear.

## The one change to try next

State exactly one behaviour in one sentence.

## Why this one

Explain the mechanism and journal evidence in plain language. Include alternatives considered only when they clarify why this action is more executable.

## Make it easy to win

- **Cue:**
- **Action:**
- **Minimum version:**
- **Win condition:**
- **If I resist:**
- **Notice afterward:**

## Confidence and unknowns

State confidence as `low`, `medium`, or `high`, with one sentence explaining what would change your view.

## Memory update

Show one of:

- `No durable memory update today.`
- `Candidate learning:` followed by a concise proposed private-memory entry.
- `Durable learning:` followed by the proposed update and why promotion criteria are satisfied.

Do not expose hidden chain-of-thought. The explanation should be a concise evidence-and-rationale summary.
