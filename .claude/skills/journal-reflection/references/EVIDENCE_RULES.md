# Evidence Rules

## Evidence hierarchy

Strongest to weakest for this system:

1. Repeated directly reported behaviour/outcomes across multiple dates.
2. Direct current report with clear context.
3. User-confirmed interpretation from a prior run.
4. Repeated inferred pattern with consistent outcomes.
5. Single inferred interpretation.

Do not let a psychologically appealing theory outrank clear contradictory evidence.

## Language calibration

Use:
- "The journal shows..." for direct observations.
- "A possible pattern is..." for synthesis.
- "One hypothesis is..." for mechanisms.
- "I don't have enough evidence to tell..." when uncertain.

Avoid clinical labels unless the user is explicitly discussing an existing professional diagnosis and the label is needed for context.
